# 🎬 MOVIE — Studio Vidéo & Photo IA Multi-API

Application web moderne et réactive pour générer des **photos** et des **vidéos IA** avec moteur anti-perte, gestion multi-clés en parallèle et mode JT satirique politique (style Wes Anderson avec chatons Shaolin).

## ✨ Fonctionnalités

- **Génération Photo IA (Text-to-Image)** : Génération rapide d'images haute définition via le modèle `agnes-image-2.1-flash`. Téléchargeables et immédiatement réutilisables comme image d'amorce pour une vidéo.
- **Génération Vidéo IA (Image-to-Video & Text-to-Video)** : Animation fluide de vos visuels avec application de styles artistiques (Cinématique, Cyberpunk, Ghibli, 90s, Naruto, Pixar, etc.).
- **Moteur Anti-Perte (Safari iOS / Mobile)** : Mémorisation persistante de la session et des IDs de génération pour ne jamais perdre une vidéo en cours de calcul lors d'un rechargement d'onglet.
- **Mode JT Multi-Partis** :
  - Flux RSS en temps réel des principaux partis politiques français.
  - Rédaction automatique du scénario par LLM.
  - Répartition des scènes en parallèle sur un pool de clés API.
  - Lecteur vidéo Canvas avec synthétiseur vocal français (TTS).
- **Compatible PWA** : Installable sur iPhone (Safari), Android et PC comme une application native.

## 🚀 Utilisation

1. Ouvrez l'application dans votre navigateur.
2. Ajoutez votre clé API (obtenue sur [platform.agnes-ai.com](https://platform.agnes-ai.com)) dans le panneau des clés.
3. Générez votre première photo ou uploadez une image, choisissez un style, et lancez la génération vidéo !
